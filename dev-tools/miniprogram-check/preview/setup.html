连不上？按这三条排查
1. 电脑上要先跑起服务：双击 启动监控.bat，控制台会打印手机该用的地址。
2. 开发者工具里勾上「详情 → 本地设置 → 不校验合法域名、web-view、TLS、HTTPS 证书」；真机点右上角「…」→ 开发调试，打开后才允许访问 http 局域网地址。
3. 想在微信里长期用（正式版），得给这台电脑套一个已备案的 HTTPS 域名反向代理，再把域名填在上面 —— 小程序正式版只认 HTTPS 白名单域名。
