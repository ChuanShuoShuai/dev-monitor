①手机扫码打开

正在获取地址…

手机要连和这台电脑同一个 WiFi / 局域网。扫完直接在浏览器里打开即可，不用装任何东西。

②用起来就三步

  1. 电脑上双击「启动监控.bat」
    第一次会引导你确认工程目录，之后每次都直接用上次的配置。
  2. 手机扫码
    页面上有四个页签：编译（实时进度 / 结果 / 历史归档）、运行（引擎日志，剧情行高亮、警告错误自动标色）、自检（红绿九宫格）、产物（截图 / 报告 / 崩溃，点开看详情）。
  3. 要编译就点「开始编译」
    手机上就能触发电脑编译并看实时进度；再点一次变「停止编译」。不想放开这个权限，把 config.json 里的 allowBuild 改成 false 即可。
